# Mohamed Gamal - Live React Portfolio

## Run
1. Open this folder in VS Code.
2. Open Terminal in the project folder.
3. Run:
   npm install
   npm run dev

Then open the Vite URL shown in the terminal.

## Live demos included
- E-Commerce Store: functional search, categories, cart, quantity controls and demo checkout.
- Task Management App: add, complete, filter and delete tasks.
- Tic-Tac-Toe: complete two-player game with win/draw detection.
- Business Dashboard: search and status filters for transactions.
